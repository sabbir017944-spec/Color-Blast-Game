# Color Blast — Match 3 Puzzle

A colorful, mobile-friendly Match-3 puzzle game built with vanilla HTML, CSS and JavaScript.

## Play
Open index.html in a browser, or enable GitHub Pages:
1. Open repository Settings → Pages.
2. Choose Deploy from a branch.
3. Select main and /(root), then Save.
4. Open the published Pages URL when deployment finishes.

## How to play
- Swap two adjacent gems.
- Match 3 or more gems of the same color to score points.
- Reach the target before your moves run out.
- Clear a level to unlock a higher target.

## Features
- Responsive 8×8 board and six gem colors
- Cascading matches and refill
- Score, target, move counter and levels
- Shuffle, restart, pause and sound controls
- No account or internet connection required during play

## Files
- index.html — game interface
- style.css — responsive visual design
- game.js — puzzle rules and game state

This is an early playable prototype. Test on multiple devices before publishing to Google Play.
